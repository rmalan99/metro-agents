# Pantallas de detalle

Orden adaptable:

1. Retorno o breadcrumb.
2. Identidad, estado, metadatos clave y acciones permitidas.
3. Navegación interna solo para áreas sustanciales.
4. Información primaria agrupada por significado.
5. Relaciones, documentos, actividad o historial cuando existan.

- Prioriza el objetivo real: consultar, validar, decidir, editar o auditar.
- Usa una columna para lectura lineal; dos solo cuando el panel secundario aporta contexto constante; tabs únicamente para áreas extensas.
- No inventes KPI, progreso, mapas, timeline, tabs ni acciones para completar una plantilla.
- Valores ausentes se muestran como no disponibles, no con datos ficticios.
- La edición breve puede usar side form; la extensa tiene ruta propia. Acciones destructivas se separan y confirman.
- Mantén semántica y formatos coherentes con el listado de origen.
- Contempla carga estructural, inexistente, error recuperable y acceso denegado.
