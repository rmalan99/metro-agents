# Dashboard administrativo

El dashboard resume trabajo accionable; no es una colección decorativa de cards.

Orden recomendado:

1. Contexto, título y período.
2. Métricas decisivas y comparables.
3. Tendencias o distribución, si existen datos reales.
4. Pendientes, alertas o excepciones.
5. Actividad reciente y accesos rápidos justificados.

- Cada KPI declara etiqueta, valor, unidad, período y origen. No inventes evolución ni porcentajes.
- Usa gráficos solo si mejoran comparación o tendencia; ofrece resumen textual y estados vacío/error.
- Tablas resumidas enlazan al listado completo y no duplican toda su funcionalidad.
- Acciones rápidas respetan permisos y representan tareas frecuentes reales.
- Desktop puede usar panel secundario; tablet lo desplaza debajo; móvil apila por prioridad.
