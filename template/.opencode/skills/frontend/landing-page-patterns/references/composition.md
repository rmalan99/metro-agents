# Composición de landing page

## Secuencia base

1. Header simple con identidad, navegación necesaria y CTA.
2. Hero con propuesta de valor, apoyo breve, CTA primario y visual real opcional.
3. Evidencia o confianza, solo con fuentes aprobadas.
4. Beneficios orientados a resultados.
5. Características o funcionamiento cuando aclaren la decisión.
6. Objeciones: integración, seguridad, proceso, precios o FAQ según producto.
7. CTA final coherente con el principal.
8. Footer con navegación y datos legales reales.

- Diferencia beneficio de característica. Evita bloques repetidos que no añaden argumento.
- Testimonios, logos, estadísticas y ratings requieren evidencia; omítelos si no existe.
- Pricing aparece solo con planes y condiciones autorizados.
- Un CTA secundario puede apoyar exploración, pero no competir visualmente con el objetivo principal.
- Formularios piden el mínimo necesario, explican privacidad y muestran carga, éxito y error reales.
