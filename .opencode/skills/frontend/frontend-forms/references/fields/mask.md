# Mask field

Use the shared field anatomy/state contract from `../../SKILL.md`. Define mask/format, empty prompt, partial-entry validation and canonical value. A mask is formatting, not proof of validity; separators are not automatically part of the backend payload.

Support paste/delete/caret behavior and appropriate mobile input. Reuse an existing compatible masking capability or assess a justified dependency under the project policy.

Verify partial/full values, paste/edit/delete and normalization without losing significant digits or characters.
