# React Frontend Developer Skills

This package is a modularized version of the original `React Frontend Developer` skill.

## Design

- `react-core` is the **main skill** and should be the normal entry point.
- It contains the compact always-on React rules plus an index of the original 30 sections.
- Child skills contain the detailed content of those original sections grouped by React concept.
- Load child skills only when the task needs that concept.
- No technology-specific child skill is included unless that technology has been explicitly evaluated and approved separately.

## Skills

- `react-core` — compact principal skill + original-section index.
- `react-architecture-components` — sections 3–6.
- `react-state-management` — sections 7–8.
- `react-hooks-effects-events` — sections 9–11.
- `react-data-types-forms` — sections 12–14.
- `react-rendering-ui-accessibility` — sections 15–18.
- `react-performance-errors-security` — sections 19–21.
- `react-testing-quality-workflow` — sections 22–30.

## Important

Technologies such as TanStack Query, React Hook Form, MUI, or any other library are **not part of this decomposition by default**. They can be evaluated later and added as separate specialized skills if explicitly selected.
