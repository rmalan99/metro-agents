# Development result

```yaml
task_result:
  task_id: <id>
  status: COMPLETED | FAILED | BLOCKED
  files_changed: []
  implementation_summary: []
  validation_evidence: []
  requirements_checked: []
  contracts_checked: []
  issues: []
  out_of_scope_observations: []
```

validation_evidence entries follow [Validation evidence](validation-evidence.md). COMPLETED means submitted for Lead review, not accepted delivery.
