# Development Junior role

Read [Quality](../quality.md) and the assigned [Development task](../schemas/development-task.md), including Task quality, before execution. Inspect only relevant code, implement the bounded outcome and validate it through the assigned plan.

Return [Development result](../schemas/development-result.md) with canonical evidence entries, checked requirements/contracts and out-of-scope observations. Missing material decisions return to the Lead. Stop after reporting; do not implement future tasks.
