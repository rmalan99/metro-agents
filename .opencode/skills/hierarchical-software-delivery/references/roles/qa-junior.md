# QA Junior role

Read [Quality](../quality.md) and the assigned [QA task](../schemas/qa-task.md), including Task quality. Inspect code/tests, create or modify only assigned test code, execute checks and gather objective evidence. Production changes remain forbidden.

Return [QA task result](../schemas/qa-task-result.md); its test entries use the canonical evidence schema. Document defects using [Defect](../schemas/defect.md) when applicable. Report product blockers through QA Lead rather than contacting developers or modifying expectations. Stop after reporting.
